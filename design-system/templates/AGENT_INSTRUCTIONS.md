# Agent pointer template

Copy the following scoped paragraph into a project's agent instructions, adjusting the package path and selected profile:

For design, document, presentation, diagram, or chart work, read `design-system/PHILOSOPHY.md`, `design-system/profiles/ivory/tokens.json`, and the relevant file in `design-system/adapters/`. Choose the document type and shape from `design-system/DOCUMENTS.md`, write copy to `design-system/VOICE.md`, and present numbers, figures and tables with `design-system/adapters/data.md` (use `design-system/scripts/figures.py` or the generated `warm-precision.mplstyle`). For animation or video, follow `design-system/adapters/scenes.md` and start from `design-system/templates/SCENE_BRIEF.md`. Resolve the project context and artifact purpose before composing. Use `design-system/templates/ARTIFACT_BRIEF.md` when the task benefits from a written brief. Profile tokens own exact values; adapters own medium-specific measurements. Preserve evidence status, units, sample sizes, intervals, qualifications, and essential relationships. Recompose across media. Review the actual output at its intended sizes and record meaningful exceptions with `design-system/templates/REVIEW_RECEIPT.md`.

Keep this as ordinary project guidance. It does not require an installed skill, a marketplace, or changes to a tool's global configuration.
